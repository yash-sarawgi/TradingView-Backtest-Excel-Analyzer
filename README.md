# TradingView Backtest Excel Analyzer

A Python tool that automatically generates **advanced performance
analytics and visual reports** from TradingView strategy backtest
exports.

Instead of manually analyzing strategy results, this tool processes
TradingView trade export files and produces a **fully formatted
analytics dashboard inside Excel**, including performance metrics, risk
analysis, and visual charts.

Designed for **systematic traders, quantitative researchers, and
strategy developers**.

# Features

## Metrics

Automatically calculates key trading statistics:

-   Total trades
-   Winning trades
-   Losing trades
-   Win rate
-   Profit factor
-   Average win / loss
-   Largest win / loss
-   Maximum consecutive wins / losses

The analyzer also evaluates strategy risk characteristics:

-   Maximum drawdown (\$)
-   Maximum drawdown (%)
-   Expectancy per trade
-   Standard deviation of returns
-   Sharpe-like ratio

## Time-Based Edge Detection

The tool analyzes strategy performance across time dimensions:

### Day of Week Analysis

Identify which trading days generate the best results.

### Hour of Day Analysis

Detect the most profitable trading hours.

### Monthly Performance

Breakdown of strategy performance across months.

This can help identify **time-based inefficiencies or edges in trading
strategies**.

------------------------------------------------------------------------

## Excel Charts

The generated Excel report includes visual charts such as:

-   P&L by Day of Week
-   P&L by Hour of Day
-   Win Rate by Day
-   Equity Curve

These allow **quick visual inspection of strategy performance**.

# Usage

## Place TradingView Export Files

Export your strategy trades from TradingView as an Excel file.

Place the exported `.xlsx` files **in the same folder as the analyzer
script**.

Example:

    TradingView-Backtest-Excel-Analyzer
    │
    ├── tradingview_excel_analyzer.py
    ├── analyze_all.bat
    ├── your_tradingview_export.xlsx

------------------------------------------------------------------------

# Analyze a Single Backtest File

Run the analyzer using the following command:

``` bash
python tradingview_excel_analyzer.py input_file.xlsx
```

Example:

``` bash
python tradingview_excel_analyzer.py VWAP_Scalping_Strategy_NASDAQ_PYPL_2026-02-13.xlsx
```

This will generate:

    VWAP_Scalping_Strategy_NASDAQ_PYPL_2026-02-13_analyzed.xlsx

The output file will contain the original sheets plus a new **Advanced
Analysis** sheet with performance metrics and charts.

------------------------------------------------------------------------

# Batch Processing Multiple Files

You can analyze **all TradingView export files in the folder at once**.

Ensure all raw TradingView `.xlsx` files are in the **same directory as
the script**, then run:

``` bash
python tradingview_excel_analyzer.py --batch .
```

The `.` indicates the **current directory**.

The script will:

1.  Detect all Excel files in the folder
2.  Analyze each file
3.  Automatically generate analyzed versions

Example:

    strategy1.xlsx → strategy1_analyzed.xlsx
    strategy2.xlsx → strategy2_analyzed.xlsx
    strategy3.xlsx → strategy3_analyzed.xlsx

------------------------------------------------------------------------

# Windows Batch Script (Optional)

Windows users can alternatively run:

    analyze_all.bat

This will automatically execute batch analysis for all Excel files in
the folder.
